Reading 1917 newsprint at scale

Newspaper pages survive as warped scans with narrow columns and pre-reform spelling. I built a pipeline to detect the page layout, transcribe each column, assemble the text, and flag uncertain readings for review.

The workflow keeps the original spelling in a source layer and produces a separate searchable layer. Its checks compare the output with the scanned page so that lost columns, duplicated lines, and unsupported text can be found.

Crime as the newspapers reported it

I coded crime reports from the Kyiv press, preserving each report’s date, printed location, offence type, and source reference. A historical gazetteer connects variant street names to a city plan while recording the uncertainty of each location.

The map is an analytical view of newspaper reporting. It is being held with the underlying records for the forthcoming book.

Editorial infrastructure for a seven-volume history

At the National Bureau of Translations I check archival references, source archival illustrations, manage production with each volume's editors, and run the Russian-to-Kazakh translation pipeline. A multi-author work of this size produces problems no single reader can hold in view, so much of the job became building tools that can.

My own chapter, “Foreign Historiography”, is accepted for volume 7.

Text pipeline

PDF extraction, paragraph repair across page breaks, a style rubric, critique, rewrite and reassembly. Interface and reports in Russian for the editors.

Fixed on real files: paragraphs lost at page breaks, inline footnote markers dropping lines, Russian capitalisation breaking cross-page joins.

Python · PowerShell

Russian to Kazakh translation

Glossary extraction that groups Russian declensions under one term, strict one-to-one paragraph alignment into Kazakh Cyrillic, and a bilingual review file for the translators.

Glossary first · aligned output

Proofreading from the PDF

Finds misplaced footnotes, copy-paste repetitions, Latin letters hiding inside Cyrillic words, and hyphenation debris, directly in the laid-out pages. Results go to a spreadsheet the editors work through.

PyMuPDF · rule checks, then model review

Cross-volume audit

Looks for contested terms that different volumes use in incompatible ways. A deterministic sweep gives recall and page anchors; a language model adjudicates each hit; the result is a register of inconsistencies for the editors.

≈3 million tokens · one command-line tool

Discussion records

More than twelve hour-long editorial discussions in Russian and Kazakh transcribed in batch, circulated so colleagues can check them and add speaker names, and summarised into reports for the project's leadership.

Finding aids and text tools

These tools make difficult sources easier to find and read. You can try two of them here: search a captured archive catalogue snapshot, or split a sample PDF into named text files. The book workflow adds searchable text to scans while keeping their appearance intact.

Presidential Archive catalogue index

A captured snapshot of the Archive of the President of Kazakhstan's electronic catalogue: 775 fonds and 2,100 inventories, searchable by title, dates and reference numbers. This snapshot contains no individual file records.

Museum collections workbook

Builds a workbook from the national e-museum catalogue: about 7,200 artefact records from 289 museums in 20 regions, with dating, material, technique, dimensions and source links, plus a coverage sheet stating exactly what was and was not collected.

Snapshot of 2 October 2026 · offline tests

PDF range splitter

A small desktop utility that cuts the text layer of a scanned book into named files by page range, with a preview of each split before export.

Windows · double-click launcher

Try it with a sample PDF · View source code

Scanned-book OCR and quality checks

A batch workflow for Russian- and Kazakh-language books adds a searchable text layer without changing the page images or dimensions. It exports Markdown and a page-level quality report, and retries pages when an existing text layer is incomplete.

Python · Tesseract · PyMuPDF · tested on difficult scans

About

I am a history student at Nazarbayev University, where my honors thesis is advised by Dr. Mikhail Akulov and Dr. Matvey Lomonosov. I work as a research assistant on Prof. Akulov's project on revolution and crime in Kyiv, 1914–1918, and at times as a data scientist.

The projects here share one question: what happens to a record of violence or disorder as it passes through clerks, editors, archives and now software. I want the instruments to be as open to criticism as the sources.
